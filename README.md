A professional, fully functional, production-ready **Smart Parking Management System** engineered for college project demonstrations and urban parking operations.

For the complete technical documentation and source code, explore the `smart_parking_system` directory.

---

## Quick-Start Terminal Commands (PowerShell)

```powershell
# 1. Navigate to project directory
cd smart_parking_system

# 2. Run automated tests to verify system integrity
python -m pytest tests -v

# 3. Launch application server
python app.py
```

Alternatively, from this root folder, you can directly launch the server:
```powershell
python run.py
```
